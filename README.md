# Uber 好單提醒

讀取 Uber Driver 派單畫面的價格與距離，**每公里 ≥ 20 元（可調）就跳通知（響鈴＋震動）**，接不接由你自己按。
不達標或讀不清楚（沒價格、價格是範圍、距離數量不對）的單不會通知，只寫進紀錄。

App 只讀畫面，**不會幫你按任何按鈕**。

## 編譯
1. 在 GitHub 建一個新的 repo，把這整個資料夾上傳（含 `.github`）
2. 到 Actions → Build APK，跑完後下載 `UberAutoAccept-apk`，解壓得到 `app-debug.apk`

## 安裝設定
1. 安裝 APK，打開 App，允許通知
2. 按「開啟無障礙設定」→ 已下載的應用程式 → 「Uber 好單提醒服務」→ 開啟
   - 若顯示「受限制的設定」：到 設定 → 應用程式 → Uber 好單提醒 → 右上角 ⋮ → 允許受限制的設定，再回去開
3. 按「測試通知」確認會響
4. 打開 Uber Driver 上線

## 設定
- 每公里門檻：預設 20
- 「公里數包含去接客的距離」：預設關（只算載客距離）；打開會用 接客＋載客 總公里數計算，比較保守

## 讀不到怎麼辦
來單後按「看最後一張派單讀到的文字」，把內容複製出來，調整 `OfferParser.kt` 的規則。
